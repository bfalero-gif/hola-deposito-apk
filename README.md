# hola! Depósito — app Android

App de control de stock, recepciones y entregas conectada a Odoo, para las
sucursales y el depósito de Hola Congelados. Terminales con lector de códigos.

## Descargar e instalar

1. Abrí este enlace desde el celular: **[Descargar la última versión](../../releases/latest)**
   y tocá el archivo `hola-deposito.apk`.
2. Android va a avisar que es de un origen desconocido. Permití la instalación
   para esta vez (Ajustes › Instalar apps desconocidas › navegador).
3. Abrí la app, cargá la conexión a Odoo y elegí la sucursal del teléfono.

El instalador no contiene contraseñas: la conexión se ingresa al abrir la app y
queda guardada cifrada solo en ese teléfono.
